# Decisions

| #   | Decision                                                                                                                                                                                                                                                     | Why                                                                                                                                                                                                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Restart the project from scratch on Expo SDK 58 instead of continuing the Phase 0 shell.                                                                                                                                                                     | The store build of Expo Go only runs the latest SDK, and the owner asked for a fresh start.                                                                                                                                                                                                                                       |
| 2   | Accounts hold balances in every configured currency rather than one currency per account.                                                                                                                                                                    | A safe or a pocket physically holds both currencies; one card per place is simpler to read than six accounts.                                                                                                                                                                                                                     |
| 3   | Exactly two currencies in the UI, chosen at onboarding; the data model allows more.                                                                                                                                                                          | Matches the request and keeps every screen legible.                                                                                                                                                                                                                                                                               |
| 4   | Fraction digits follow everyday use, not strictly ISO 4217 (IQD = 0).                                                                                                                                                                                        | People quote dinars without fils; showing fils would be noise.                                                                                                                                                                                                                                                                    |
| 5   | Receipts are their own table linked to transactions, with a pending state.                                                                                                                                                                                   | Enables "snap now, add the amount later" without fake zero-amount transactions.                                                                                                                                                                                                                                                   |
| 6   | Reports exclude transfers, exchanges, opening balances and adjustments.                                                                                                                                                                                      | They move money between places; counting them would inflate income and spending.                                                                                                                                                                                                                                                  |
| 7   | Reconciliation appends adjustments.                                                                                                                                                                                                                          | History stays explainable and auditable.                                                                                                                                                                                                                                                                                          |
| 8   | Repository tests run on `node:sqlite` through a driver interface.                                                                                                                                                                                            | Real SQL coverage in CI without an emulator; the expo-sqlite adapter is ten lines.                                                                                                                                                                                                                                                |
| 9   | Writes use the same connection with a promise queue instead of `withExclusiveTransactionAsync`.                                                                                                                                                              | Works on web, avoids per-connection PRAGMA drift, and the app has no concurrent writers.                                                                                                                                                                                                                                          |
| 10  | Zustand store with a `version` counter plus a `useQuery` hook instead of a cache library.                                                                                                                                                                    | Small surface, predictable refreshes after each write.                                                                                                                                                                                                                                                                            |
| 11  | Daily local notifications in the native build use the default (`bestEffort`) delivery.                                                                                                                                                                       | A reminder a few minutes late is fine and needs no extra permissions.                                                                                                                                                                                                                                                             |
| 12  | Inter via `useFonts` rather than the font config plugin.                                                                                                                                                                                                     | Works in Expo Go and in builds alike.                                                                                                                                                                                                                                                                                             |
| 13  | App lock uses the device biometrics / passcode and is a UI gate only.                                                                                                                                                                                        | Honest about the security boundary; no custom PIN to forget.                                                                                                                                                                                                                                                                      |
| 14  | Web is a preview surface only.                                                                                                                                                                                                                               | Receipt files are kept in memory there; SQLite runs in WebAssembly for screenshots and quick checks.                                                                                                                                                                                                                              |
| 15  | Ship the iPhone version as a Home Screen web app built from the same code.                                                                                                                                                                                   | The owner uses an iPhone and does not want Expo Go; native iPhone installs need a $99/year developer account. The web app is free, offline and needs no computer.                                                                                                                                                                 |
| 16  | sql.js with IndexedDB snapshots on the web instead of expo-sqlite's web build.                                                                                                                                                                               | expo-sqlite on the web needs cross-origin isolation headers that GitHub Pages cannot send; sql.js runs everywhere and the database is small enough to snapshot after each write.                                                                                                                                                  |
| 17  | Nightly reminder on the web is a daily Calendar event with an alert.                                                                                                                                                                                         | Web apps cannot schedule local notifications; web push would require a server, which this app deliberately avoids.                                                                                                                                                                                                                |
| 18  | Backup and restore to a JSON file, including photos, on every platform.                                                                                                                                                                                      | With no cloud, removing the web app from the Home Screen deletes its data; a file in iCloud Drive is the safety net.                                                                                                                                                                                                              |
| 19  | Publish with GitHub Pages from Actions; Cloudflare Pages documented for private repositories.                                                                                                                                                                | Free hosting with HTTPS, needed for the service worker and camera.                                                                                                                                                                                                                                                                |
| 20  | Photos are re-encoded to JPEG at most 2000 px in the web app.                                                                                                                                                                                                | Keeps browser storage small while staying readable.                                                                                                                                                                                                                                                                               |
| 21  | Drop Android; target the iPhone web app and an optional native iOS build only.                                                                                                                                                                               | The owner uses an iPhone and does not need an Android version; fewer targets means less to maintain and test.                                                                                                                                                                                                                     |
| 22  | People are ledger accounts of class `person`, and debts are transfers tagged with an action.                                                                                                                                                                 | Balances, statements, deletion, restore and report exclusion all follow from the existing double-entry rules instead of a parallel debt list.                                                                                                                                                                                     |
| 23  | Four explicit actions (loan given, loan received, repayment received, repayment made) plus "Pay out / Receive" buttons that pick the natural action from the current balance.                                                                                | The stored action keeps the history readable; the buttons save choosing when the direction is obvious.                                                                                                                                                                                                                            |
| 24  | Debts stay in one currency; settling in the other currency is out of scope for now.                                                                                                                                                                          | Never mixing currencies keeps every balance and statement exact.                                                                                                                                                                                                                                                                  |
| 25  | One due date per party rather than per loan.                                                                                                                                                                                                                 | Simple and enough for personal use; per-loan schedules would need allocation rules.                                                                                                                                                                                                                                               |
| 26  | Standard bookkeeping wording in the interface: receivable and payable, Dr and Cr, debit and credit columns, b/f and c/f, party, reconcile.                                                                                                                   | The owner is an accountant. Only labels changed; stored identifiers and backups are unaffected, and reconciliation entries now default to the note "Reconciliation adjustment".                                                                                                                                                   |
| 27  | The account is chosen from always-visible tiles with balances, defaults to the account last used for the same kind of entry, previews the balance after posting and warns (without blocking) below zero; the confirmation names the account and offers Edit. | Choosing the wrong account was easy when it sat in a row, pre-filled from whatever was posted last (including opening balances). A forced choice every time was rejected as slower for daily entries; the visible tiles, preview and named confirmation catch mistakes instead.                                                   |
| 28  | One app-wide "hide amounts" switch (the eye button), stored as a setting so it survives a restart, applied in the shared money formatter.                                                                                                                    | Showing the app to someone should take one tap and leave nothing readable. A single setting read by MoneyText covers every screen at once; keeping it after a restart means a relaunch never exposes amounts. Typed input, shared statements and exports stay real because they are explicit actions.                             |
| 29  | A split is one expense entry with a receivable line per party, not an expense plus separate loans.                                                                                                                                                           | It matches the journal (Cr Bank 30; Dr Food 12; Dr Ali 18), keeps the bank account showing the single payment that appears on the bank statement, and makes editing, deleting and restoring atomic with no linking. Reports already net an expense's lines, so only your share is spending; counts were changed to count entries. |
| 30  | Statement files are written by small pure TypeScript encoders in the app (PDF with built-in Helvetica, XLSX as a stored zip) instead of libraries or a print dialog.                                                                                         | Works offline in the Home Screen web app and the native build with one code path, adds no dependency, is unit-tested in Node, and produces small files with selectable text. The web print dialog does not give a file to share on iPhone.                                                                                        |
| 31  | When a statement contains text Helvetica cannot show, the web app draws the same layout on a canvas and the PDF holds the pages as pictures.                                                                                                                 | A party named in Arabic must never export as question marks. The browser's text engine shapes any script; embedding and shaping fonts in the PDF writer would be far larger. Excel files carry any script natively.                                                                                                               |
| 32  | Statement export replaces the CSV statement; amounts in files are plain numbers with the currency code stated once, and Excel cells hold real dates and exact decimals.                                                                                      | PDF is for sending and printing, Excel for working on the figures; a third format added nothing. Stating the currency once reads like a professional statement and avoids symbols outside the PDF font.                                                                                                                           |
| 33  | Exchange is its own entry type in the form and on Home, still stored as a transfer between two currencies, and may stay within one account.                                                                                                                  | It was hidden behind a switch inside Transfer and could not exchange cash inside one pocket, the most common case. Storage is unchanged, so no migration and old exchanges open in the new form.                                                                                                                                  |
| 34  | The exchange form links three boxes (give, receive, rate): a typed rate works out the amount received, two typed amounts show the rate; the last rate is offered but never applied by itself. No rate is stored or fetched.                                  | Money changers quote a rate, so typing amount and rate is the natural entry. Both amounts stay the user's own and visible before saving; the maths is exact integer arithmetic. Offering rather than pre-filling the last rate avoids posting at a stale rate unnoticed.                                                          |
